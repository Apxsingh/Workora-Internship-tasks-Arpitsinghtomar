# Web Traffic Analytics

**Workora Virtual Internship — Data Analytics**

Analyze website traffic to understand visitor engagement, traffic channel performance, bounce rates, session duration, and conversion behavior using Python and data visualization.

## Project Overview

The objective of this project is to analyze website traffic data and identify opportunities to improve website performance. The analysis focuses on traffic sources, session engagement, conversion rates, and page-level performance.

The project uses Python, Pandas, NumPy, Matplotlib, and Seaborn in a single Jupyter Notebook.

## Objectives

- Analyze website traffic from different acquisition channels.
- Calculate bounce rate and average session duration.
- Measure pageviews per session.
- Compare conversion rates across traffic channels.
- Examine page-level engagement and conversion performance.
- Visualize important web analytics metrics.
- Generate a PDF dashboard summarizing the analysis.

## Dataset

**Dataset:** `web_traffic_sample.csv`

**Source:** [Workora Sample Web Traffic Dataset](https://workora.in/datasets/web_traffic_sample.csv)

The dataset contains session-level website traffic information, including:

| Column | Description |
|---|---|
| `SessionID` | Unique identifier for a session |
| `Date` | Date of the session |
| `PagePath` | Recorded page path |
| `Source` | Traffic acquisition source |
| `DeviceCategory` | Device used during the session |
| `SessionDurationSec` | Session duration in seconds |
| `PageViews` | Number of pages viewed in the session |
| `Converted` | Whether the session resulted in a conversion |
| `BounceRate` | Session-level bounce indicator in the supplied sample |

The initial sample contains 10 rows and 9 columns. The notebook inspects data types, missing values, duplicate sessions, and invalid values before calculating metrics.

## Analysis Workflow

### 1. Data Loading and Inspection

- Load the CSV dataset using Pandas.
- Inspect the dataset dimensions and column names.
- Review data types and descriptive statistics.
- Check missing values and duplicate session IDs.

### 2. Data Cleaning and Validation

- Standardize whitespace in text fields.
- Convert date and numerical columns to appropriate data types.
- Standardize conversion labels.
- Identify duplicate session IDs and invalid values.
- Prepare the dataset for analysis.

### 3. Key Performance Indicators (KPIs)

**Bounce Rate**

Percentage of sessions flagged as bounced:

`Bounce Rate = (Bounced Sessions / Total Sessions) × 100`

**Average Session Duration**

`Average Duration = Total Session Duration / Number of Sessions`

**Conversion Rate**

`Conversion Rate = (Converted Sessions / Total Sessions) × 100`

**Average Pageviews per Session**

`Pageviews per Session = Total Pageviews / Number of Sessions`

The notebook also compares these metrics across traffic channels.

### 4. Traffic Channel Analysis

The original traffic sources are grouped into four requested categories:

| Original Source | Traffic Channel |
|---|---|
| Google Search | Organic |
| Google Ads | Ads |
| LinkedIn | Social |
| Direct | Direct |

The analysis compares session counts, conversion counts, conversion rates, bounce rates, average session duration, and average pageviews per session.

### 5. Page-Level Performance

Page-level analysis examines:

- Number of sessions associated with each recorded page.
- Conversions associated with each page.
- Average session duration.
- Average pageviews.
- Bounce behavior.

This helps identify pages that may warrant further investigation.

### 6. Data Visualization

The notebook generates the following charts:

- Website sessions by traffic channel.
- Bounce rate by traffic channel.
- Average session duration by traffic channel.
- Conversion rate by traffic channel.
- Sessions by recorded page.

### 7. PDF Dashboard

The notebook generates a PDF report containing an overall KPI summary and the main visualizations.

**Dashboard output:** `outputs/web_traffic_dashboard.pdf`

## Limitations

- The supplied sample contains only 10 sessions, so the results are illustrative and may not represent broader website behavior.
- The dataset does not contain a unique user identifier, so unique users and pageviews per unique user cannot be reliably calculated.
- The `BounceRate` field contains binary values in the sample and is treated as a session-level bounce indicator. This interpretation should be confirmed against the dataset documentation.
- Each session has one recorded `PagePath`. The dataset does not provide ordered page events or explicit funnel stages, so a reliable sequential conversion funnel and page-to-page drop-off rate cannot be reconstructed.
- Traffic channel comparisons are based on the supplied source mapping and may need adjustment if additional source labels are present.
